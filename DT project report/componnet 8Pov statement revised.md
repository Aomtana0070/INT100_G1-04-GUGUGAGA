# Point of View (PoV) Statement Revised


## PoV เดิม 
### We met
ผู้ใช้สวนสาธารณะหลากหลายกลุ่ม ตั้งแต่นักเรียน ครอบครัวที่พาลูกมาเดินเล่น ผู้สูงอายุที่มาออกกำลังกาย และผู้ที่มาพักผ่อน โดยมาใช้งานเป็นประจำ 3-4 วันต่อสัปดาห์ เลือกสวนนี้เพราะใกล้บ้าน เดินทางสะดวก และมีบรรยากาศธรรมชาติที่ดี

### We were surprised to notice
แม้ผู้ใช้ทุกคนจะพูดว่าพอใจกับสวนนี้ แต่เมื่อพูดถึงการใช้สิ่งอำนวยความสะดวกจริงๆ กลับแสดงความกังวลและไม่สบายใจอยู่เสมอ โดยเฉพาะเรื่องห้องน้ำสกปรกมีกลิ่นเหม็น ที่นั่งไม่เพียงพอ และที่จอดรถไม่พอ

### We wonder if this means
ความพอใจที่ผู้ใช้พูดถึง อาจไม่ได้มาจากความต้องการของผู้ใช้จริงๆ แต่เพราะมีทางเลือกน้อย ผู้ใช้จึงเลือกที่จะมาใช้มากกว่ายินดีใช้งาน แท้จริงแล้วอาจไม่ได้มาจากความสุข และปัญหาความสะอาด ความปลอดภัย และสิ่งอำนวยความสะดวก คือเงื่อนไขพื้นฐาน ที่ถ้าไม่ได้รับการแก้ไข ผู้ใช้พร้อมจะลดความถี่หรือเปลี่ยนไปใช้สวนอื่นทันทีที่มีตัวเลือก

### Core insight
ผู้ใช้สวนดูพึงพอใจภายนอก แต่กำลังทนใช้งานท่ามกลางปัญหาพื้นฐานด้านความสะอาด ความปลอดภัย และสิ่งอำนวยความสะดวก เพราะไม่มีทางเลือกอื่นที่ดีกว่า

### It would be game-changing to
ทำให้ผู้ใช้รู้สึกมั่นใจและปลอดภัย ในทุกครั้งที่ใช้งานสิ่งอำนวยความสะดวกของสวน จนเปลี่ยนจากการทนเป็นเลือกใช้สวนนี้ด้วยความเต็มใจ

## PoV Statement (Revised)

### We met (ไม่เปลี่ยนแปลง)
ผู้ใช้สวนสาธารณะหลากหลายกลุ่ม ตั้งแต่นักเรียน ครอบครัวที่พาลูกมาเดินเล่น ผู้สูงอายุที่มาออกกำลังกาย และผู้ที่มาพักผ่อน โดยมาใช้งานเป็นประจำ 3-4 วันต่อสัปดาห์ เลือกสวนนี้เพราะใกล้บ้าน เดินทางสะดวก และมีบรรยากาศธรรมชาติที่ดี

### We were surprised to notice (ไม่เปลี่ยนแปลง)
แม้ผู้ใช้ทุกคนจะพูดว่าพอใจกับสวนนี้ แต่เมื่อพูดถึงการใช้สิ่งอำนวยความสะดวกจริงๆ กลับแสดงความกังวลและไม่สบายใจอยู่เสมอ โดยเฉพาะเรื่องห้องน้ำสกปรกมีกลิ่นเหม็น ที่นั่งไม่เพียงพอ และที่จอดรถไม่พอ

### We wonder if this means (revised)
ความพอใจที่ผู้ใช้พูดถึงอาจสะท้อนแค่ "แก่นของสวน" คือบรรยากาศธรรมชาติและทำเลที่ตั้งซึ่งเป็นจุดแข็งจริง แต่ปัญหาด้านความสะอาด ความปลอดภัย และสิ่งอำนวยความสะดวก ทำหน้าที่เป็น **เงื่อนไขพื้นฐาน (hygiene factors)** ของประสบการณ์ กล่าวคือ ไม่ได้เป็นสิ่งที่สร้างความสุขเพิ่มเมื่อมีอยู่ แต่จะบั่นทอนความพึงพอใจและความถี่ในการมาใช้งานทันทีเมื่อขาดหายหรือมีปัญหา

### Core insight (revised)
"ผู้ใช้พึงพอใจกับแก่นของสวน (ธรรมชาติ ทำเล) แต่ความสะอาด ความปลอดภัย และสิ่งอำนวยความสะดวกที่ยังไม่ได้มาตรฐาน กำลังกัดกร่อนประสบการณ์อย่างเงียบๆ โดยที่ผู้ใช้เองอาจไม่รู้ตัวว่านี่คือสิ่งที่ทำให้ 'พอใจแบบมีเงื่อนไข' ไม่ใช่ 'พอใจเต็มร้อย'"

### It would be game-changing to 
ยกระดับสิ่งอำนวยความสะดวกและความปลอดภัยของสวนให้ได้มาตรฐานขั้นพื้นฐานอย่างสม่ำเสมอ เพื่อให้ผู้ใช้ทุกกลุ่มได้สัมผัสประสบการณ์ที่มั่นใจและปลอดภัยเต็มร้อย ไม่ใช่แค่พอใจกับสิ่งที่มีอยู่บางส่วน
